- **XNU**
iOS is *kindofbutnotreally* similar to MacOS, which uses the Unix-like darwinOS. 
If you're familiar with Unix, you'll know about the kernel. iOS uses Apples own kernel, called the XNU kernel.
The XNU kernel is a bit different from Linux though.
